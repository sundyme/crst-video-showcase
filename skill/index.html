工作流程

8 步，标黄的地方需要你拍板

  1. 选题与脚本3 个选题，约 290 词脚本，数字有出处你选题
  2. 定风格同一帧出 3 个方向，写风格规范你选风格
  3. 配音与时间轴逐句合成，生成词级时间轴你选声音
  4. 素材PlugKit 画接线；Ray 角色库；生图后端出背景道具；产品用真图自动
  5. 画面一套场景代码，参数切换横竖版式自动
  6. 音效与配乐导出音效清单，合成、闪避、响度统一自动
  7. 出片与验收接线校验、二维码解码、独立审片你提意见
  8. 交付成片、字幕、章节、发布文案、开发日志你确认提交

安装

把安装包交给 AI，让它来装

不需要 GitHub 账号，也不用自己敲命令。安装包里有一份写给 AI 的安装指南，Claude Code 或 Codex 会按你电脑的实际情况处理，某一步出错会自己换办法。

  1. 从公司群下载安装包文件名是 crst-safety-video-v1.6.zip（16 MB，以群里最新版本为准）。存到「下载」文件夹：微信里右键文件选「另存为」；飞书、钉钉默认就存在「下载」里。不用自己解压。
  2. 交给 Claude Code 或 Codex打开任意一个，把 zip 拖进对话框（不拖也行，它会去「下载」里找），再粘贴这句话发送：
    帮我安装 crst-safety-video skill。安装包是我拖进来的 zip；没拖的话，在「下载」文件夹里找 crst-safety-video-v 开头的 zip，找不到就问我。先解压到临时文件夹，读里面的 INSTALL.md，按它把 skill 装好、补齐依赖、跑环境检查，最后告诉我结果和还需要我做的事。
  3. 中途点允许它要运行命令、联网、写入文件时会征求你同意，点允许。装工具要下载一两百 MB，等它跑完。少数电脑要装 Homebrew，需要输入开机密码：它会给你一行命令，请你粘贴到「终端」里运行，这是唯一可能要你动手的地方。
  4. 填配音 key，重新打开它会在屏幕上弹出一个输入框，把 MiniMax key 粘贴进去点「保存」就行，key 不会出现在对话里。最后重新打开 Claude Code，或新开一个 Codex 会话。
不要把 key 直接发在对话里。需要填 key 时让 AI 弹出输入框；如果已经发了，请找维护者换一个新 key。

常见问题

常见问题

我完全不懂代码，能用吗？

能。这套流程就是按这个前提设计的：安装、配置、做片、排错都通过对话完成，AI 自己运行命令、改文件。你要做的是挑选题、挑风格、听配音、看成片提意见。

AI 让我输入密码或在「终端」里运行命令，安全吗？

只有安装 Homebrew（Mac 上常用的软件安装工具）时需要，命令来自 Homebrew 官网，要输入开机密码是正常的。其他情况 AI 不应该向你要密码；遇到可疑要求，先问维护者。

装完了，但 Claude Code / Codex 里用不上

装好后要重新打开 Claude Code，或新开一个 Codex 会话，已经开着的会话看不到新 skill。还不行，就说「检查一下 crst-safety-video 的环境」。

弹出「需要安装命令行开发者工具」

新电脑第一次装时 macOS 会弹这个框，点「安装」，等它装完（几分钟），再告诉 AI 继续。

没有 MiniMax key 能用吗？

能先做选题、脚本、风格和画面，只有生成配音需要 key。拿到 key 后说「帮我填 MiniMax key」，再让它配音，画面会自动对齐新的配音。

没有 ChatGPT 账号能生图吗？

能。有 OpenAI 或 Gemini 的 key，说「我想用 Gemini 生图，帮我配好」。公司有内部生图工具也能接，找维护者。

会不会泄露 key？

key 通过弹出的输入框保存在你自己电脑上（~/.config/crst-safety-video/），不在安装包里，AI 和脚本都不会显示内容。只要不把 key 发在对话或群里就安全。

我自己补的 Ray 姿势，更新时会被覆盖吗？

不会。更新时会自动搬到新版，旧版整份备份。好用的姿势可以发给维护者，收进下一版安装包。

我用的是 Codex，不是 Claude Code，能用吗？

能，流程一样。Codex 默认不联网，配音和生图会被拦，说「Codex 老是提示没网络，帮我设置好」就行。独立审片如果开不了子 agent，它会请你新开一个会话。

可以换画风吗？

可以，而且每支片都会换。skill 固定的是流程，不是画风。目前做过警示海报和纸片拼贴两种。插头电线的外观也会跟着画风调整，结构和校验不变。

能做 CRST 以外的品牌或主题吗？

流程本身通用，但素材和规则是按 CRST 和用电安全写的。换品牌要替换模板里的 logo、二维码、产品图，以及 references/product-and-brand.md 里的产品事实表。

竖屏底部为什么总是空着？

TikTok、Reels、Shorts 的底部约 380 像素会被平台的标题、按钮挡住，skill 规定这里不放重要内容。

Windows 能用吗？

没验证过，目前只支持 Mac。

技术说明

不懂代码的同事可以跳过这一节，下面这些 AI 都会自己处理。

手动安装（不用 AI）

在「终端」里运行，版本号按实际改；缺的工具按环境检查里 → 的提示补上。

D=$(mktemp -d); unzip -q ~/Downloads/crst-safety-video-v1.6.zip -d $D zsh $D/crst-safety-video/scripts/install.sh

装到 ~/.claude/skills/crst-safety-video 或 ~/.codex/skills/crst-safety-video，两个都有时只放一份、另一个放链接。参数：--claude --codex --force（允许降级）。

配置文件与命令行工具

配置在 ~/.config/crst-safety-video/config.env（权限 600）；环境变量优先。

python3 ~/.claude/skills/crst-safety-video/scripts/doctor.py # 环境检查 python3 ~/.claude/skills/crst-safety-video/scripts/config.py show # 看配置（key 不显示内容） python3 ~/.claude/skills/crst-safety-video/scripts/config.py set MINIMAX_API_KEY # 弹框输入 key python3 ~/.claude/skills/crst-safety-video/scripts/config.py set IMAGEGEN_BACKEND gemini
生图后端

所有生图都走 tools/imagegen.py，后端由 IMAGEGEN_BACKEND 决定，留空按下表顺序自动选第一个可用的。同一组系列图（例如 Ray 某个姿势的闭嘴、张嘴、眨眼三张）要用同一个后端做完。

后端需要适合
codex本机 Codex CLI：ChatGPT 桌面版自带，或 brew install codex默认首选，用 ChatGPT 账号额度，不需要 key。一批图在同一会话里生成，系列图更一致
openaiOPENAI_API_KEY；可选 OPENAI_BASE_URL、OPENAI_IMAGE_MODELOpenAI 或任何兼容网关的图像接口；带参考图时自动走改图接口
geminiGEMINI_API_KEY；可选 GEMINI_IMAGE_MODELGoogle Gemini 图像模型，改图时人物一致性较好
antigravity本机 Antigravity 应用开着Google AI Pro 额度，单张 2 到 4 分钟
commandIMAGEGEN_COMMAND 命令模板接入公司内部或其他任何生图工具

接入其他生图工具（command 后端），占位符 {out} {prompt_file} {refs} {size}：

IMAGEGEN_BACKEND=command IMAGEGEN_COMMAND=mytool gen --out {out} --prompt-file {prompt_file} {refs}
常用渲染命令

在项目的 代码工程 目录里：

# 接线校验（横竖两版都要通过） uv run --with playwright python render_film.py --o h --check 0.1 # 静帧 uv run --with playwright python render_film.py --o h --stills 3,20,45 --out ../渲染/静帧_h # 成片（竖屏把 h 换成 v） uv run --with playwright python render_film.py --o h --out ../成片/片名_16x9_v1.mp4 --audio ../音频/mix.wav
Ray 角色库的做法

新姿势用 library/ray2d/source/base.png 做母版改图（闭嘴帧），再分别只改嘴、只改眼睛得到张嘴帧和眨眼帧；tools/process_ray2d.py 抠绿幕、印真 logo、切口型和眨眼补丁；验收后 scripts/ray2d_library.py push <项目> 收回角色库。场景里用 act(时间, '姿势名') 切动作。
